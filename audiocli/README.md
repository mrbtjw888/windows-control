## Usage cli

audiocli - control system audio

Commands:
  list
      List active audio sessions

  volume <process> <value>
      Set volume (0-100)
      Or relative: +10 / -10

  mute <process>
  unmute <process>

  control <action>
      playpause | next | prev | volup | voldown | mute

  master <value>
      Set volume (0-100)
      Or relative: +10 / -10

  mastermute
  masterunmute
